**玩家承诺**　亲手锻出一把有自己做法的刀，带它打比赛，再把这把刀和它的成绩收入卡册。

**本轮制作目标**　跑通「一把刀、五道工序、一场试斩、一张卡、一份账单」。首轮让玩家拿到完整作品，第二轮让玩家带着一个自己理解的目标开炉。

## 2. 产品定位与世界设定

当代架空环境。玩家经营一间个人工坊，参加面向锻造者的锻刀大赛。各场用人工标准靶检验作品，工坊可以接工艺委托，藏刀阁保存成刀档案和比赛记录。工作台、物料商、赛事与收藏册就构成完整世界。

- **工坊**负责让玩家做决定。看矿脉、控制游戏化炉温、选择锤点、挑柄件，每次操作都在作品上留下可见结果。
- **锻刀大赛**负责验证。纸绳看连斩，木靶看破壳和贯通，定点靶看命中精度。同一种刀也能靠更熟练的手势打好。
- **藏刀阁**负责保存作品。卡正面像一件现代印刷收藏品，背面回答「怎么做的、打过什么、花了多少、挣了多少」。

核心受众是喜欢短局触控、轻构筑和收藏的玩家。目标单炉 90–150 秒，单场 12 或 30 秒。首页只突出「锻刀」，「赛事」「藏刀阁」是并列的次入口。长线内容由工坊里看得见的技艺、靶场挑战和首辑卡位构成。

## 3. 核心循环与前十分钟

**选材料 → 五道工序 → 成刀与入册 → 带此刀试斩 → 写入履历、奖励和账单 → 开下一炉或让这把刀再打。**

| 节点 | 玩家经历 | 提示与回报 |
|---|---|---|
| 开局至第一锤 | 两种不同方向的免费工坊料任选，打灯看一条线索，按住鼓风后松手 | 提示出现在操作旁。首炉可一次保底浇注，保留已完成的步骤 |
| 第一把刀 | 六锤即可收锤。用直刀图样，比较轻柄和稳柄，确认后亮出刀名、首卡及一项专长 | 作品自动归档。主行动「带此刀试斩」，次行动「查看卡背」 |
| 12 秒试斩 | 先做一划免费演练，再打三波。斩断累计 ≥3 为有效，单划三斩另发赛印 | 战报给一条证据，例如「木靶用了三划」。奖励、赛印和下次目标同时可见 |
| 第二次行动 | 「同刀再赛」或「接木靶对照委托」 | 复用同一套靶。试重锋图样时突出「能不能少一划破壳」，卡背记下两把刀各自的实测 |

首刀试斩有效后开放自由快赛、每日挑战和学徒路径。借刀练习从开局可进，可采用与自有刀相同的固定靶阵。首轮演练只教一划，规则留在赛前与战报。

## 4. 五道锻造工序

| 工序 | 玩家选择 | 反馈与设计规则 |
|---|---|---|
| **选料** | 左右比较候选。打灯看矿脉，敲石辨稳定，擦窗看矿芯 | 名称、价格、擅长方向常驻，已发现线索按候选保存。购买前可自由对照。确认才扣 CR 并保存炉次 |
| **精炼** | 按住鼓风、松开散热，在合格区累计质量。达标时选择现在浇注或再争一点 | 同屏显示「现在浇注」的结果与下一档收益。指针有短预测尾，合格带同时用形状、文字和音色表达 |
| **锻打** | 点击刀腹、刃侧、刀尖或底栏对应按钮。第六锤可收，常规炉额外强化至多四锤 | 第 2/4/6 锤依次显钢色、定轮廓、出主纹。每个有效落点都有受理反馈。继续前显示预计收益、疲劳和风险 |
| **装配** | 在轻柄、稳柄、饰柄中选一件，比较能力和代价 | 切换即时预览整刀，能放大看柄。标准件含在炉料成本，6 CR 同属性外观件确认后扣费 |
| **鉴定** | 看整刀亮相、命名，可跳过封签直接试斩 | 封签目标 ≤0.9 秒，特殊版目标 ≤1.2 秒。归档刀体配方、六维、工艺档和当炉流水后进入试斩页 |

五个矿系承担不同构筑入口。河床叠钢偏韧性、潮汐层纹。霜晶矿偏锋利、冷色晶纹。熔渣铁偏强度、致密暗内芯。陨星黑矿偏灵性、黑灰细点。赭铁层矿偏设计、暖铜层理。每类后续做三种不同轮廓，品相线索来自夹杂、裂隙和矿芯清晰度。

精炼采用 0–100 的游戏刻度。首炉合格带宽 16，累计约 2 秒。常规合格带宽 10–12，累计约 3 秒且质量 ≥22 可浇注，约 6 秒可争良好，12 秒按当前质量结算或给一次低档浇注。普通炉的精炼保底记质量 22。正式挑战炉在开炉前明示更高门槛与全损风险。

## 5. 构筑、收锤与工艺分

**六维。** 强度决定重靶破壳，韧性决定赛内耗损，锋利决定贯通，工艺影响相同手势下的效率，设计影响靶心容差和连斩时间窗，灵性轻度影响表现分。标准图样试制从六维各 64 起步，加图样、料系、精炼、锤点和柄件修正后限制在 20–150。

| 锤区 | 单次有效贡献 | 赛场验证 |
|---|---|---|
| 刀腹 | 强度 +2、韧性 +1 | 重靶更少划数，长场完赛耐久更高 |
| 刃侧 | 锋利 +2、工艺 +1 | 轻靶更易贯通，相同轨迹连斩更多 |
| 刀尖 | 设计 +2、灵性 +1 | 靶心容差、稳定得分与连斩窗口 |
| 柄件示例 | 轻柄锋利 +4、工艺 +2、韧性 −2 | 轻靶效率更高，重靶耐久有取舍 |

前六锤稳定成形。每区前四锤贡献属性与工艺，继续打同一区仍记为成形次数并留下局部锤痕。第七锤起，额外强化单项总增益上限 +4。用回潮作检验样例，河床叠钢加韧性 8、锋利 2，良好精炼加韧性 3、工艺 5，四刃侧两刀腹加轻柄，得到 **68 / 75 / 78 / 75 / 64 / 64**。

额外四锤基础疲劳 +18/+22/+25/+30。每锤按材料稳定度加 0/+5/+10，良好精炼每锤减 4，单锤最少增加 8。预计疲劳在 ≤45、46–70、71–90、91–99 时，崩纹率为 0%、5%、12%、25%。达到 100 可收锤，或一次使用缓冲减 22。普通炉崩纹只失本锤强化并进入装配。挑战炉可以报废，材料成本按 40% 向下取整返还。风险用炉次种子与锤序确定，重开客户端能找回同一结果。

**工艺分**建议采用 `四舍五入(0.55 × 精炼质量 + 0.45 × 成形质量)`。成形质量从 60 起，前六锤有效贡献每锤 +5，成功强化每锤 +2.5，最高 100。A/B/C/D 分界为 85/70/55。精炼 70 和六次有效贡献得到 79、档 B。工艺分用于鉴定和委托，选刀优先看该靶实测。旧鉴定分与历史成绩保留在作品档案内，按所属规则版本展示。

## 6. 比赛、靶具与手感

**一划只结算一次。** 用输入时刻的靶位与归一化手势采样，按接触顺序处理。轻靶接触即显断面，重靶第一阶段破壳，第二阶段贯通，定点靶要看到靶心是否命中。挥空给短淡轨迹。每局恢复赛用耐久。后台、设置、来电冻结计时并取消旧手势。

| 模式 | 试制规则 | 成长与解锁 |
|---|---|---|
| 练习 | 12 秒，自选靶或固定参考轨迹。可借刀 | 开局开放，记录结果 |
| 首刀试斩 | 0/4/8 秒三波。纸绳列阵、轻靶加木靶、新角度轻靶。斩断 ≥3 有效 | 第一张成刀卡后。单划三斩另获赛印 |
| 自由快赛 | 30 秒，热身、混合、冲刺各 10 秒。斩断 ≥4 有效。赛前选一个可完成的专项 | 首试有效后。可选同划三靶、两次破重靶、三次命中靶心 |
| 每日挑战 | 30 秒固定靶序与规则。固定试刀和自带刀各有成绩记录 | 同日共享一份奖励。重赛可刷新成绩 |
| 六系流派 | 锻压、锋刃、精密、淬彩、复合、过载，各五阶 | 依次检验破重靶、连斩、靶心、破冰接斩、软硬同破和耐久 |
| 全国赛 / 三刀巅峰 | 全国同一把刀过五轮。巅峰三把不同刀各走一轮 | 任一流派过能手开全国。全国夺冠且有三把合格刀开巅峰 |

首轮使用纸绳、木和一类轻靶。活用当前赛事已有的纸牌、竹节、菠萝、冰、凝胶、钢和盾等内容。扩展优先给已有靶补真实可读的四个状态，完整、受损、断为两片、碎屑。靶具整块与断面使用同一素材锚点，低画质也保留切面和命中瞬态。

**分数与战报。** 开发首轮沿用当前按靶分别计分的配置，保留原成绩口径。试制重点是「切了几划」「同一划斩几靶」「剩余耐久」与专项达标。V5.1 中的轻/加固/重靶 28/51/100 与 V3.0 的 40/65/100 属于两套提案。等同靶对照稳定后再用回放试验分布和成绩迁移。战报固定为总成绩、关键动作、CR 与赛印、下一步四行。 [现有靶具与计分](https://github.com/Imthechou/MyBlade/blob/e4e09914e9d3743be0d668b8355e32c1f6f1c007/game/src/v19/arena/trial.js#L16) · [靶序与流派配置](https://github.com/Imthechou/MyBlade/blob/e4e09914e9d3743be0d668b8355e32c1f6f1c007/game/src/v19/arena/courses.js#L24)

## 7. 信用点与作品账单

**CR 是工坊的统一预算。** 用于材料、外观和可选服务。每笔交易记来源、炉次、金额和收据 ID。刀做好后回填刀 ID。玩家在钱包看所有流水，在卡背看这一把刀的净额。委托交付后，刀继续归玩家收藏和出赛。

| 材料档 | 采购 | 验收 | 工艺委托达标另给 | 只做成刀 | 成刀并完成委托 |
|---|---:|---:|---:|---:|---:|
| 工坊料 | −14 | +6 | +12 | −8 | **+4** |
| 精选料 | −22 | +9 | +16 | −13 | **+3** |
| 珍藏料 | −34 | +12 | +22 | −22 | **0** |

- **首炉。** 新档 30 CR，首单材料免费，首刀专属验收 +8，第一次完成有效首刀赛 +4，整圈结束有 42 CR。首刀使用专属验收，等第二炉开放常规委托。
- **工艺委托。** 开炉前锁定一份，预览图样、目标和金额。工坊示例要求河床叠钢、两次刀腹锤、合格成刀。精选示例为三次刃侧锤、精炼质量 ≥65。珍藏示例需要指定矿系、两个锤区各连续两锤、精炼质量 ≥65。达标一次结算。
- **赛事收入。** 练习 0。快赛有效 +4，同局完成锁定专项再 +4。每日首个有效 +12。流派五阶首通分别 +12/+16/+20/+24/+28，重复达标 +6。全国和三刀赛每轮通过 +6，记给该轮用刀。全国首次冠军 +30，三刀首次冠军每把参赛刀另 +12。借用固定试刀的收益记钱包赛事流水。
- **低额与损失。** 余额低于 14 CR 可开免费基础复开炉。成功后补余额到 14，记录一笔补助。本炉发放补助，不叠加常规验收和委托。同一时间只有一个活跃炉次。主动放弃前看已付金额；普通炉可续做。挑战炉返还材料采购额的 40%，向下取整。
- **长期消耗。** 主要是炉料和自选外观。赛事免费报名。后续商业化可评估直购装帧主题。首批六个收藏版位通过可复现的锻造和赛事条件获取。

**回潮的常规账单**　工坊料 −14，验收 +6，工艺委托 +12，快赛及专项 +8，净额 **+12 CR**。同样条件下精选料净 +11，珍藏料净 +8。连续三炉用工坊料且只拿验收，30 会降到 6；免费复开成功补 8 回到 14。工坊料委托达成率约 67% 可覆盖纯锻造成本。珍藏线需要达标才能靠工艺回本，作品有独立纹样和赛用方向可追。

现档钱包与已经拿到的奖励照原额导入。初次迁移建立余额起点，历史刀仅显示能追溯的收支。配置上线前，从当前用户余额和赛事收入分布抽样，校验常规料复开率、低额弹出率和奖励节奏。 [现有归档与结算](https://github.com/Imthechou/MyBlade/blob/e4e09914e9d3743be0d668b8355e32c1f6f1c007/game/src/core/v19Progress.js#L67)

## 8. 刀卡与藏刀阁

一把成刀拥有稳定档案 ID，一张卡代表一个具体作品。做出两把同名刀会进入卡册两次，系列图鉴只点亮该版位一次。**作品属于同一个收藏体系，稀有度决定印法，赛事履历决定赛印。** 同一把普通刀赢比赛也可显示真实冠军印。

### 正面、卡背与 3D

| 位置 | 内容和行为 |
|---|---|
| 正面 | 63:88 竖版。展示完整刀体、刀名、稀有度与一项专长。已有系列版位可以附在角上。具备记录时显示胜场或冠军印。刀尖、柄尾和轮廓留白优先 |
| 卡背 | 六维、原鉴定评分、工艺、材料、柄件与代表纪录。接入钱包账本后可看逐笔收支 |
| 赛前小卡 | 复用同一刀图，突出本轮靶型与适配度。赛后回写原作品 |
| 藏刀阁列表 | 双列静帧，按现有分页显示。点开作品或独立加入比较。后续筛选可扩到材料、版位和赛印 |
| 单卡 | 进入卡面，横拖或方向键看箔光。可切到卡背，或按需打开 3D 检视，关闭后释放舞台 |
| 图鉴与断刀册 | 图鉴展示版位达成条件。报废作品独立保存炉料、原因、主要选择和退款 |

### 六档印法

沿用项目实际的六个稀有度键。层次来自底纸、印刷图案、边框结构和反射范围。每档可以凭**档位文字与纹样**辨识，小屏静止状态也应成立。

| 项目稀有度 | 视觉处理 | 角度变化 |
|---|---|---|
| 普通 `common` | 石墨哑纸、疏斜纹、单细边。刀体用干净斜光 | 卡面可静态观赏，哑纸无动态箔 |

出图层来自项目自己的刀模型和材质配方。纹路和箔图形用 CSS 分层。检视比例控制在横倾 ±10°、纵倾 ±6°，列表保持静帧。动效遵循项目与系统偏好，减少动效时保留纸纹、边框和文字。首批珍贵感主要靠完整刀体与分层印刷，赛印表达真实战绩。

### 首辑与回访

首辑 F01 包含回潮（直刀耐久）、霜线（唐刀精密）、夜坠（弯刀重靶）、熔渣铁重锋、赭铁定纹、自由签名位。对应 F01—01 至 F01—06。系列版位描述工艺主题，稀有度仍取自该次鉴定。首晚做两把不同方向的刀，解锁同靶对比。随后可追签名、套系缺位、同刀一划 3/4/5 靶里程碑或新流派。首发熟练度加成试制上限 8%。

## 9. 美术、动效与移动端

**品牌和场景。** 暗紫作为界面底色和主操作提示。工坊以石墨、真实冷钢和局部炉火建立深浅层级。赛场用冷白体育照明，靶的轮廓和切面比环境更亮。藏刀阁用纸张、凹纹和箔面营造现代收藏印刷。三个舞台共享字体、编号和组件，分别负责做刀、试刀和看刀。

**刀体质量。** 正视和 45° 清楚看到刀脊、刃面和握柄过渡，移除特效后仍可读纹理与形体。矿系决定底色和纹样母题，精炼改纯净与粗糙度，锤点改局部细节和材料方向，装配只覆盖柄件。验收用同一把刀在工位、鉴定、卡册、战报四处核对；模型与材质以相同配方重建。

| 事件 | 视觉、音频与操作 |
|---|---|
| 锤击 | 一帧内亮受理落点，90–120 ms 接触，110–150 ms 回弹。火星只在接触处。忙碌时明确反馈「已排队」或「回弹中」 |
| 试斩 | 刀轨跟手，接触、断裂、余响按事件出现。一划多靶只弹一条合并反馈，同时留出下一个靶的位置 |
| 鉴定 | 整刀先稳定入画，再走一束反射光，最后落作品名和工艺档。跳过能立即试斩 |
| 卡册 | 列表只用静帧，打开单卡才倾斜。银箔、棱镜和铜印反射只在局部，视觉层不改变数值 |

竖屏覆盖 320–430 CSS px，主行动区 ≥48 px，次级 ≥44 px，兼顾安全区。锤区有按钮等价操作，重要状态同步提供颜色、图形和文字。声音、震动与减少动效可各自设置。首页、精炼和战报只放当前最需要的信息，六维和长账单放展开层。项目使用实际游戏刀模与同光位出图做终审，新素材用同机位对照轮廓、灯光与材质后接入。

## 11. 六周交付范围

| 周期 | 可玩的交付 | 评审通过条件 |
|---|---|---|

| **第 3–4 周** | 扩到回潮、霜线、夜坠三例，引入快赛专项、工艺委托、卡背和两刀同靶对照 | 固定轨迹下两种构筑各有一项明显优势。实际玩家能复述哪道工序改变了优势 |

## 12. GitHub 交付、AI 评审与验收

项目使用 [Imthechou/MyBlade](https://github.com/Imthechou/MyBlade)。AI 从最新 `main` 建功能分支，在仓库内提交设计、实现和回归用例，开 Draft PR 供检查。AI 检查差异、运行用例、阅读截图和构建结果，需要返工时继续在该分支提交。项目负责人检查 PR 与证据，指出使用体验和审美需要调整的部分。

| 职责 | AI 要交的证据 |
|---|---|
| 策划评审 | 首轮路径、关键取舍、阶段范围。每个试制数字标明与现行规则的关系 |
| 代码评审 | 基线与提交 SHA、主要入口、旧档和异常路径、重点文件及已修复的问题 |

| 功能验收 | 自动用例、通过/失败项和复现方式。启动、滚动、触摸、键盘、对比、命名和减少动效各能复查 |
| 性能与发布前验收 | 构建与证据产物，可用设备与测试范围。真实设备数据和浏览器模拟数据逐项注明 |

### 全项目验收指标

- **首轮体验。** AI 用稳定种子和固定手势检查首炉、6 锤、首赛与结算。开始到第一锤中位目标 ≤45 秒，首赛结束中位目标 ≤150 秒。玩家漏斗作为后续实测数据，首访独立完成率目标 ≥75%，首赛后十分钟内再赛或第二炉目标 ≥45%。
- **比赛手感。** 320/390/430 CSS px 检查无遮挡。用固定种子和 30/60/120 Hz 采样回放同一轨迹，命中顺序与计分一致。分别验证快锋的连斩、重锋的破壳、精密的靶心差异。
- **收藏。** 六档使用同刀快照对照，档位文字、框纹、材质可分。三屏尺寸和减弱动效下可打开卡面、切卡背和使用原有对比与试刀。对已完成赛事只展示实际赛印。500 张卡维持分页和静帧缩略。
- **经济与可靠性。** 覆盖首轮、正常、未达标、报废、低额复开、重复点击、后台恢复和两标签页。每笔实付与实赚可追踪，重复扣发为 0。

评审先落地三项，一把刀的完整闭环、同靶对照、作品账单。六档印法可以独立在藏刀阁验收。后续沿这个分支交付方式做完整玩法接入。
