锻刀大赛 4.0.4 · 高清精简单套资源版

Windows：先安装 Node.js 22+，双击“开始游戏.cmd”，游戏自动打开 http://127.0.0.1:8123/ 。
macOS / Linux：终端运行 ./启动游戏.sh 或 npm start。
不要双击 index.html，游戏需要本地 HTTP 服务；无需 npm install，核心游戏可离线运行。

优化：
1. 刀模仅保留 assets/models/ 的单套全品质 GLB（含 1024² ORM）；新版 V19 和旧渲染器共享该套资源，移动端不再额外打包重复刀模。
2. 9 款赛事靶具使用 800x928 高分辨率透明 WebP；移除重复 PNG 和原 116x135 嵌入式低清靶图。
3. 修复赛事首次命中可能锁定低清靶图的问题；Retina 高清画布启用动态像素预算，控制 GPU 负担。
4. 保留游戏原有离线音频、刀具 PBR、美术色彩、赛事与锻造规则。

基线：GitHub main 4.0.3 (250399bfd3ae0b2b9b8d73ff31950088b18b4169)。
此次属于从发布工件完成的独立运行版优化，并未自动更改 GitHub main。

注意：本地 Chromium 受环境策略限制，未能完成这一优化包的浏览器实玩验收；已通过源码自动测试、资源检查和本地服务检查。
